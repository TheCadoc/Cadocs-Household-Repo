Sync across devices

Your data is stored in one GitHub Gist that only you can write to. GitHub gists cannot be truly private, only "secret": anyone who has the gist link can read it. The passphrase below encrypts the data in your browser before upload, so the gist is unreadable without it. Use a passphrase.

First device: 1) create a token with only the gist scope, 2) paste it and choose a passphrase below, 3) press Create and connect.
Other devices: open this page, paste the same token and passphrase, enter the gist ID (or use the setup link), press Connect.

Advanced

Your browser is blocking local storage for this file, so changes will not persist. Use Export backup before closing, or open the file in Chrome or Edge.

Track where each document is, not the document itself. Put the file path or folder name in "Where stored". Do not type passwords or full card numbers anywhere in this tracker.
